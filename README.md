
# Rhythm Typer Nomination Checker 🔍

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)
![Python 3.14](https://img.shields.io/badge/python-3.14-blue)


A small python script that allows you to easily check current Rhythm Typer Beatmap Nominator's quota and nomination history.

## Features

- Display all profiles summary
- Display only recently nominated maps (last 90 days)
- Display all nominated maps
